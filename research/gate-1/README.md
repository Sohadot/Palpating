> **Gate 1 closes only when the category survives both positive evidence *and*
> adjacent-category falsification.** Pass 2 narrowed the **atomic-property layer**;
> Pass 2.1 corrects the interpretation — the **category** is not limited to intrinsic

Gate 1 is **research before classification**. Its purpose is to test, against the
literature, whether **Physical-Sign Intelligence** is a defensible category and to
locate the **precise limits of Digital Palpability** — not to build or approve an
ontology.

> **The governing sequence:** literature → evidence objects → candidate classes →
> falsification → **Gate 2** governance. Gate 1 stops before Gate 2. Nothing here
> approves or hardens the ontology, standard, protocol, or engine.

## The five research axes

Every property is examined across these axes (the columns of the evidence matrix):

1. **Physical / mechanical property** — the bodily property itself (stiffness,
   elasticity, deformation, tone/tension, pressure, mobility, texture, …).
2. **Sensing modality** — how it is transduced (SWE, MRE, tactile/force sensing,
   strain sensing, wearable mechanical sensing, myotonometry, IMU, imaging).
3. **Digital representation** — the form the signal takes (scalar value,
   parametric map, waveform, image, joint angle).
4. **Spatial / temporal context** — point vs field; static vs dynamic; localized
   vs whole-organ; in-vivo vs phantom; lab vs field.
5. **Limitations / uncertainty** — what bounds the representation (operator/force
   dependence, subcutaneous confound, anisotropy, loading/motion bias,
   reproducibility, validation gaps).

## Falsification questions (what Gate 1 must answer)

- **Q1 — Category defensibility.** Is "Physical-Sign Intelligence" a coherent
  technical category with a real, converging substrate, or a loose grouping of
  unrelated measurements?
- **Q2 — Digital Palpability limits.** For each property, is it *representable*
  today (strong evidence), *emerging* (partial), or *speculative* (weak)? Where
  exactly does representability end?
- **Q3 — Property survival.** Which v0.1 candidate properties are evidence-backed
  enough to survive to Gate 2, which should merge, and which should be dropped?
- **Q4 — The universal limit.** What is true of *every* modality that bounds any
  Digital-Palpability claim?

## Result so far

Pass 1 established a well-evidenced landscape. Pass 2 attacked it and found the
**atomic-property layer is narrow** (elasticity/modulus, structural stiffness,
deformation/strain, superficial viscoelastic tone, surface roughness). **Pass 2.1
corrects the interpretation:** narrowing the atomic layer did **not** shrink the
Palpating category. Concepts that are not atomic properties — pressure, resistance,
asymmetry, mobility, texture — remain inside Palpating in other governed roles
(interaction-derived sign, response relation, comparative sign, functional/kinematic
expression, decomposable umbrella) **provided defensible physical provenance
exists**. The asset governs the chain *physical meaning → provenance → elicitation/
sensing → representation → interpretation → representation gap*, which belongs to the
verb *palpating* itself.

## Pass 3 result

Pass 3 answered the governing question. Key outcomes:
- The seven proposed provenance modes were found to **conflate two axes** and were
  reshaped into a **2-axis model: Nature (State / Response / Dynamic / Relational /
  Functional) × Access (Direct / Elicited / Model-inferred / Comparative-derived)**,
  each concept carrying a mandatory **Representation Gap**.
- **Every concept was reclassified, none deleted:** "texture" and "pressure" proved
  to be **multi-provenance** (texture → surface roughness / tactile-inclusion /
  internal-heterogeneity; pressure → intrinsic IOP-type state vs contact-interface),
  each cell individually defensible.
- **Boundary defined:** Palpating owns the *binding layer* (provenance →
  representation → gap), not biomechanics/wearables/haptics/digital-biomarkers/
  elastography. Inclusion needs defensible provenance; exclusion means **no**
  provenance (device artifact, or pure performance with no physical binding).
- **Gate 1 closure recommended**, pending user ratification.

**Genuinely open (for Gate 2):** operational test for the "Functional" boundary;
whether "Dynamic" is a distinct Nature; whether "Access" is an ontology axis or
Protocol metadata; promotion of evidence objects into `SOURCE_REGISTER.md`.
**No Gate 2 governance begins until the user ratifies Gate 1 closure.**
