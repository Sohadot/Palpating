# Publication Standard — Palpating

**Version:** 0.1 · **Status:** Binding · Subordinate to `ASSET_THESIS.md`.
This is the asset's **quality gate**, required of every Tier 1 asset by the
methodology's `FOUNDATION_DOCTRINE.md` (Inheritance Requirement #2). It
instantiates the ten portfolio **Non-Negotiables** with concrete, checkable
values, and defines what Palpating will and will not accept as future content
(Execution Order Step 8).

**The gate is blocking. One failed criterion means no publication.** There is no
"publish now, fix later."

---

## Part A — Non-Negotiables, instantiated and checkable

| # | Non-Negotiable | Palpating check (blocking) |
|---|----------------|----------------------------|
| 1 | No phantom surfaces | No page in sitemap/nav lacks the seven admission elements (`REFERENCE_LAYER_POLICY.md` §2). No draft/thin/placeholder page is reachable. |
| 2 | No broken structure | Zero broken internal links, zero orphans, zero dead anchors; every page has a canonical URL and complete metadata. Automated link+route check passes. |
| 3 | No ungoverned claims | Every statement typed as sourced fact / interpretation / framework language; every type-1 claim links to an `S-nnn` (`CLAIMS_GOVERNANCE.md`). Claim-coverage check passes. |
| 4 | No random SEO | No keyword-driven pages, no auto-generated thin pages, no fake comparison surfaces. Every page is an ontology node (`SEO_AND_INTERNAL_LINK_GOVERNANCE.md`). |
| 5 | No trust-lowering revenue | No monetization present that a strategic buyer would remove; monetization only per `MONETIZATION_DOCTRINE.md` and only after the monetization gate. |
| 6 | No unregistered surfaces | Every public route is in the route registry. Unregistered route ⇒ the page does not exist. |
| 7 | No silent change | Any change to thesis, ontology, standard, protocol, or policy has a `DECISION_LOG.md` entry and a version bump. |
| 8 | No partial language launches | Only English (`en`) is governed in v0.x. No second language ships until its layer is complete and governed. |
| 9 | No hidden infrastructure | Static-first, dependency-free HTML/CSS/JS. No secrets, no undisclosed data collection, no unreviewed third-party scripts. |
| 10 | No desperation | No acquisition-urgency language, public buyer targeting, or marketplace framing on any surface (`ACQUISITION_READINESS.md`). |

A build that fails any row does not publish. Automated checks cover 1, 2, 3, 6,
7, 9; human review covers meaning, restraint, and safety (4, 5, 8, 10).

## Part B — Entry criteria for new content

- **New reference page:** must meet all seven admission elements
  (`REFERENCE_LAYER_POLICY.md` §2) and pass the claim-coverage check.
- **New ontology class:** admitted only via `CLASSIFICATION_ARCHITECTURE.md` §3
  entry criteria, at Gate 2, with a logged decision.
- **New source:** admitted only via `SOURCE_GOVERNANCE.md` §1.
- **Doctrine-layer update:** must not downgrade the conceptual position; passes
  the methodology's `operating-rules/quality-standard.md` dimensions (strategic
  clarity, structural coherence, conceptual integrity, language quality, time
  durability).

## Part C — Prohibited content types (with rationale)

- Diagnostic, treatment, disease-detection, or longevity content — implies a
  medical service the asset is not (`CLAIMS_BOUNDARY.md`).
- Score/ladder/certification surfaces for Digital Palpability — manufactures
  false measurement authority (DEC-002).
- Acronym-ontology or pseudo-standard branding — false framework signal (DEC-003).
- Listicles, how-to palpation guides, SEO comparison tables in standard form —
  content-resource formats that destroy the imitation barrier
  (`CATEGORY_ARTIFACT_STANDARD.md`).
- Any interface pattern in the Interface Governance prohibited list.

## Part D — Publication gates (per event)

Before any publish, material expansion, or income activation, run the
methodology's five gates (`operating-rules/publication-and-monetization-gates.md`):
Structural Stability · Conceptual Integrity · Authority Readiness · Revenue
Compatibility · Anti-Mobility Discipline — each Pass / Revise / Delay / Reject.
Any non-Pass blocks the transition.

> **A sovereign asset becomes stronger when exposed, not weaker. If exposure
> weakens it, it was not ready.**
